# Hanzii Minimal

A lightweight, zero-dependency web app for learning Chinese characters — stroke order animations, pinyin, and English translation, all in the browser.

**Live demo → [kyuubi0323.github.io/Hanzii-minimal](https://kyuubi0323.github.io/Hanzii-minimal)**

---

## Features

- **Stroke order animation** — watch each stroke drawn in the correct order, looping continuously
- **Pinyin** — tone-marked romanization displayed below every character
- **English translation** — the full phrase is translated automatically on draw

## Usage

1. Type one or more Chinese characters into the input field (e.g. `学习汉字`)
2. Click **Draw** or press **Enter**
3. Each character animates with its pinyin label; the English translation appears below
